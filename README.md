
# Qwentum_x1
________________________________________________________________________________________________________________________________________________________________________________
                       
                         
Название: Qwentum_x1     
                          
________________________________________________________________________________________________________________________________________________________________________________

 
Описание:
Этот проект представляет собой роботизированного робота, разработанную для образовательных целей и экспериментов в области робототехники. В его основе — связка Raspberry Pi 4 (как главный управляющий микрокомпьютер), Arduino Uno + CNC Shield V3.0 (для низкоуровневого управления двигателями) и ESP32 dev module (управление по Bluetooth, практически не используется). Корпус машинки полностью напечатан на 3D-принтере, что позволяет легко модифицировать дизайн и заменять компоненты. Для передвижения используются шаговые двигатели NEMA17, и драйвера DRV8825, обеспечивающие точное и контролируемое движение. Raspberry Pi отвечает за управление машинкой, соединение с сервером управления, работу с камерой, отправку данных с сайта управления на Arduino, и в будующем мозгом для ИИ. Arduino, в свою очередь, управляет шаговыми двигателями с помощью драйверов. Связь между устройствами осуществляется через USB-последовательный порт и UART-последовательный порт.

Модули:                                                                                                                                                                         
                                                                                                                                                                                
Управление:                                                                                                                                                                     
    Микрокомпьютер: Raspberry Pi 4 B <-+-> ( Python )                                                                                                                           
    Микроконтроллер: Arduino Uno <-+-> ( C )                                                                                                                                    
    Микроконтроллер: ESP32 dev module ( C ), (использовалась изначально для управления по Bluetooth)                                                                            
                                                                                                                                                                                
Питание:                                                                                                                                                                        
    Аккамулятор: С бустера QS3 hoco. (переделан из 4S в 3S)                                                                                                                     
    Плата BMS: BMS 3S 40A                                                                                                                                                       
    Регулятор напряжения: 300 Вт 20A DC-DC (ограничивает ток для моторов т.к. шаговые двигатели могут потреблять большие токи бескорыстно, особенно при малых оборотах)         
    Регулятор напряжения: LM2596S 10W DC-DC /12V -> 5V/ ( параллельно подключённые, для Raspberry Pi, Arduino, ESP32 и может быть чегото ещё)                                   
                                                                                                                                                                                
Сенсоры:                                                                                                                                                                        
    Камера: Raspberry pi 4 CAM OV5647 3.6mm 75° IR  5MP                 [!] В разработке [!]                                                                                    
    Wi-Fi адаптер: AR9271 (с функцией мониторинга...)                   [!] В разработке [!]                                                                                    
                                                                                                                                                                                
Каркас:                                                                                                                                                                         
    Корпус: Полностью напечатан на 3D принтере пластиком ABS+ (изначально был сделан внутренний "Эндоскелет", а потом уже "Экзоскелет" - который гараздо прочнее чем   первый   
    Колёса: Сборные из двух частей, полностью напечатаны на 3D принтере пластиком ABS (делал по дизайну колёс марсохода Curiosity)                                             
                                                                                                                                                                                
Двигатели:                                                                                                                                                                      
    NEMA17: Передвижение                                                                                                                                                        
    28BYJ-48: Вращение башни по оси XY                                  [!] В разработке [!]                                                                                    
    SG-90 180°: Вращение башни по оси YZ                                [!] В разработке [!]                                                                                    
                                                                                                                                                                                
                                                                                                                                                                                
Языки программирования: Python, C, HTML и JavaScript                                                                                                                            
                                                                                                                                                                                
                                                                                                                                                                                
Коммуникация: HDMI, USB, WiFi: SSH (Raspberry Pi Connect) и сайт управления и Bluetooth
